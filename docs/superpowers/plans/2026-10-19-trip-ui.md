# Trip UI Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace always-on geofence alarms with a single active trip driven by a native foreground location service, a live progress notification, an arrival alarm (optionally full-screen), and a new Home + bottom-sheet UI.

**Architecture:** Kotlin owns trip execution (`TripService` foreground service, `TripStore` persistence, `TripNotifications`, `ArrivalActivity`). Flutter owns destinations in SQLite (schema v3) and the UI; it drives trips through the `are_we_there/native` MethodChannel and observes them through the `are_we_there/trip` EventChannel. Spec: `docs/superpowers/specs/2026-10-19-trip-ui-design.md`.

**Tech Stack:** Flutter 3.38.9 / Dart 3.10.8, drift 2.x, Kotlin 2.2, play-services-location 21.3, Robolectric 4.16.1 (SDK 35 sandbox), JDK 17, compileSdk/targetSdk 36, minSdk 24.

```kotlin
object TripMath {
    private const val EARTH_RADIUS_M = 6_371_008.8
    const val NEAR_METERS = 2_000.0
    fun distanceMeters(lat1: Double, lng1: Double, lat2: Double, lng2: Double): Double {
        val dLat = Math.toRadians(lat2 - lat1); val dLng = Math.toRadians(lng2 - lng1)
        val a = sin(dLat / 2).pow(2) + cos(Math.toRadians(lat1)) * cos(Math.toRadians(lat2)) * sin(dLng / 2).pow(2)
        return 2 * EARTH_RADIUS_M * asin(sqrt(a.coerceIn(0.0, 1.0)))
    }
    fun progress(start: Double, current: Double) = if (start <= 0) 1.0 else (1 - current / start).coerceIn(0.0, 1.0)
    fun isArrived(distance: Double, radius: Double) = distance <= radius
    fun updateIntervalMillis(distance: Double) = if (distance > NEAR_METERS) 30_000L else 5_000L
    fun formatDistance(meters: Double): String = if (meters >= 1000) String.format(Locale.US, "%.1f km", meters / 1000) else "${meters.roundToInt()} m"
}
```
